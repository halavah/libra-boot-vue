## 保留的限制

1. 部分业务页面需要自己的后端。抽查 `/layout/onboard_test4/onbApplicant` 时，权限接口 `/development-api/onboard/sys/personInfo/checkPermission` 返回 404；页面结构能显示不表示权限和业务流程可用。
2. 静态 SFC 加载器需按原方式使用 5174 静态 HTTP 服务。已验证 Element demo01、Element demo05、Ant Design Vue demo01 能显示页面和图表；全局样式缺失另见第 4 项。通过 Vite 直接访问同一静态加载入口可能空白，不能混作相同运行模式；加载器实现没有被另写或替换。
3. 原 `test/views.json` 有 8 个入口未在其指定位置找到，保留清单，不创建空页面或改指其他实现：
- `ant-design-vue/demo06-less不可用`
- `element/demo06-less不可用`
- `device/cjsbgzms`
- `device/gltjlxzb`
- `device/mbjk-month`
- `device/mbjk-week`
- `device/sbgztj`
- `device/sgbhgl`

4. Vite 会提示部分 `/public/` 资源应从根路径访问；原静态入口的路径写法仍保留。静态 HTTP 根与 Vite 的资源映射不同，不能把两种运行方式混为一谈。 原始静态 HTTP 根下，两个 test 页面引用的 `/styles/global.css` 以及 ECharts demo02 引用的 `/styles/style.css` 缺失；这些原有路径问题未通过改写目录或复制新样式隐藏。
5. 手机号、证件号使用无实际身份含义的占位值，严格表单校验可能拒绝；原校验逻辑保持不变。请使用自有隔离测试数据，不提交真实个人资料。
6. 未逐项验收所有业务流程、备用实现、TypeScript 静态加载、全部浏览器与实体手机；未进行穷尽性安全审计。模式扫描与构建不能证明绝无敏感信息或漏洞。
